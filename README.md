# AI Adoption & Productivity Analysis Using Power BI

## Project Overview

A Power BI Business Intelligence project analysing AI adoption, usage behaviour, productivity, satisfaction, and time savings across 288 users.

The project transforms user-level AI adoption data into a four-page interactive dashboard designed to provide executive insights, behavioural analysis, performance analysis, and user segmentation.

## Business Questions

- Which AI tools have the highest adoption?
- What are users primarily using AI for?
- How frequently do users interact with AI?
- How does AI usage relate to productivity?
- How does AI usage relate to satisfaction?
- Which users demonstrate higher AI adoption and productivity?
- How are AI users distributed geographically?
- Which user segments require further investigation?

## Dashboard Pages

### 1. Executive AI Intelligence Overview

Provides an overview of:

- Total users
- Average AI usage
- Average productivity
- Average satisfaction
- AI usage vs productivity
- User type distribution

### 2. AI Usage Behaviour

Analyses:

- AI tool adoption
- AI usage purposes
- AI usage frequency
- Geographical distribution

### 3. AI Performance Insights

Examines:

- AI usage vs productivity
- AI usage vs satisfaction
- Time savings
- User-level performance
- AI power-user profiles

### 4. AI User Segmentation

Users are classified using AI usage and productivity benchmarks.

The four segments are:

- AI Champions
- High Adoption / Lower Productivity
- Low Adoption / High Productivity
- Low Adoption / Low Productivity

## Data Preparation

The dataset was standardised before analysis. Inconsistent AI tool names were consolidated into consistent categories, including ChatGPT, Gemini and Copilot. Unclassified values were grouped under "Other".
